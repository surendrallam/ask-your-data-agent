# Claude API prices used for every cost figure

Checked on 2 Nov 2026 at https://platform.claude.com/docs/en/about-claude/pricing (Anthropic's pricing page). USD per million tokens.

| Model | Base input | 5-minute cache write | 1-hour cache write | Cache hit | Output |
|---|---|---|---|---|---|
| Claude Haiku 5.5 (prompts up to 100,000 tokens) | $0.10 | $0.125 | $0.20 | $0.01 | $0.50 |
| Claude Haiku 5.5 (prompts over 100,000 tokens) | $0.50 | $0.625 | $1.00 | $0.05 | $2.50 |
| Claude Sonnet 5.5 | $2.00 | $2.50 | $4.00 | $0.10 | $10.00 |
| Claude Opus 5.5 | $4.00 | $5.00 | $8.00 | $0.20 | $20.00 |

Notes from the same page:

- Cache hits on Opus 5.5 and Sonnet 5.5 cost 0.05x the base input price; other models use 0.1x.
- Haiku 5.5's prompt length counts all input tokens, including cache reads and writes.
- Any request that defines tools adds a tool-use system prompt of 286 input tokens on all three models (tool_choice auto).
- The Batch API halves input and output prices. This project does not use it: the agent is a multi-turn tool loop and the benchmark measures latency.

The same numbers are in `src/askdata/config.py`; `tests/test_costs.py` checks the cost maths against them.
